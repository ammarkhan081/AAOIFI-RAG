# Data boundary

`data/manifests/` is for public source metadata, hashes, access dates, and licensing decisions.

`data/private/` is the intended local-only location for licensed AAOIFI source material after written access and redistribution terms are confirmed. It is ignored by Git. Do not store raw standards in a tracked directory.

`data/evaluation/` is reserved for expert-approved evaluation metadata and labels. Do not add a pilot set, derived clauses, or examples until Phase 1 decisions are complete.
